# Compact source-data contract

This directory is reserved for small, curated tables used to regenerate paper
figures. It must not contain raw `.h5ad`, checkpoints, giant parquet/CSV
matrices or derived outputs that can be regenerated from the local data tree.

The PTL-v2 pilot writes compact prediction, deployment-feature, outcome, fold,
RQ1 and G4 comparison tables here. These tables are source data for review,
not a replacement for the ignored prediction arrays.
