# Cover Letter Draft: Knowledge-Based Systems

Dear Editors,

We submit "Context-stress evaluation and perturbation transportability reliability for single-cell virtual-cell predictions" for consideration in Knowledge-Based Systems.

This manuscript develops a reliability layer for AI predictions under structured context shift. Using harmonized single-cell perturbation signatures, we define context-stress split families, compare five transparent full-gene baselines, and show that model rankings change between random, perturbation, combination, support, dataset, and external-transfer regimes. We then introduce PTL, a model-agnostic reliability model that uses support, novelty, confidence, and context-distance features to decide whether an existing prediction should be retained or abstained from.

The paper is aligned with Knowledge-Based Systems through its focus on reliability modeling, interpretable context features, failure-mode taxonomy, and decision-support style selective prediction. The failure-mode atlas gives a structured account of where predictions degrade rather than presenting a single aggregate score.

We have kept the manuscript claims bounded. The study is an evaluation and reliability framework over benchmark artifacts, not a claim of complete biological mechanism recovery or final superiority of any model family.

Sincerely,

The authors
