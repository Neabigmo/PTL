# Cover Letter Draft: EAAI

Dear Editors,

We are pleased to submit the manuscript "Context-stress evaluation and perturbation transportability reliability for single-cell virtual-cell predictions" for consideration at EAAI.

The paper addresses a central AI evaluation problem in computational biology: prediction models can perform well under random splits while failing under context shifts that matter for perturbation reasoning. We introduce a context-stress benchmark for single-cell perturbation signatures, evaluate transparent full-gene baselines across multiple stress regimes, and add a model-agnostic Perturbation Transportability Layer (PTL) that filters false transportability better than naive confidence.

The work fits EAAI because it emphasizes reliable AI methodology, reproducible evaluation design, calibrated keep/abstain decisions, and bounded interpretation. The contribution is not a new biological intervention model; it is an evaluation and reliability framework that can be layered over different perturbation predictors.

All claims are intentionally scoped to benchmarked single-cell perturbation signatures. The manuscript does not make deployment, treatment-selection, or universal-model claims. It provides figure-ready evidence tables, deterministic draft figures, and explicit limitations to support transparent review.

Sincerely,

The authors
